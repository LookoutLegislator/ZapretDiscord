> WinDivert иногда распознаётся антивирусом.  
> Это средство перехвата и фильтрации сетевого трафика, необходимое для работы zapret.
> Его могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит компоненты WinDivert к потенциально опасным или хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения при этом обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите проверку PUA — потенциально нежелательных приложений. Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете, как работают исключения, лучше добавить нужный каталог в исключения. В противном случае рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте пункт "Использовать безопасный DNS" и укажите DNS-провайдера, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант предпочтителен
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/LookoutLegislator/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, это действие обычно не требуется

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Для поиска подходящей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Чтобы включить запуск вместе с системой, выберите **`service.bat`** → `Install Service` → *подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск выбранной стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные действия:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения этого параметра стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние — включено или выключено.
  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  
  Эта настройка полезна при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается текущий режим:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP сопоставляется со списком
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — выполнить диагностику распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно заметить в панели задач.  
Если этого не случилось, обратитесь к [#522](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущая версия hosts окажется устаревшей, программа предложит обновить файл вручную:  
  - Скопируйте содержимое открывшегося блокнота целиком
  - Найдите созданную папку с файлом `hosts` и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените прежние аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа не гарантирована. Если инструкция не помогла, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/LookoutLegislator/tg-ws-proxy) либо с любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Работа стратегий не гарантируется постоянно.**
> Обнаружение используемого метода может привести к тому, что ранее рабочая стратегия через некоторое время перестанет помогать.
> В этом репозитории есть много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Откройте `service.bat` → `Run Diagnostics` и проверьте, нет ли ошибок

- Удостоверьтесь, что адрес нужного ресурса присутствует в списке доменов или IP-адресов

- Проверьте другие варианты (**`ALT`**, **`FAKE`** и остальные)

- Выполните полную переустановку по инструкции ниже

- Дополнительные сведения есть в [#765](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие нужные данные
- Перезагрузите устройство
- Выполните `service.bat` → `Remove Services`
- Запустите `service.bat` → `Run Diagnostics`; при наличии ошибок исправьте их и в конце подтвердите действие клавишей Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/LookoutLegislator/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите «Применить», затем «ОК»
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте доступ к нужным ресурсам. Если очередной вариант не работает, закройте программу через значок замка в панели задач и попробуйте следующий
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` → `Install Service` → нужная стратегия

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Узнайте имя службы через командную строку Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться
- Переберите остальные стратегии, особенно если раньше всё работало
- Дополнительная информация находится в [#251](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Для начала выясните, с какой стратегией открывается YouTube, и запустите именно её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord и определите, помогла ли очистка кэша
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, временно пользуйтесь ею
- Если Discord не открывается и в браузере, снова проверьте все стратегии: бывает, что YouTube доступен на одной стратегии, а Discord — нет
- См. также [#252](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/LookoutLegislator/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси, найденный в интернете

### Не работают игры

Игр много, поэтому проверить и исправить проблемы каждой из них невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не сработало, дополнительно включите `ipset any`

Учтите: режим `ipset any` способен нарушить открытие большого числа сайтов. Поэтому не оставляйте его включённым постоянно. Лучше определить все IP-адреса, используемые игрой, и внести их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/LookoutLegislator/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Добавлять адреса для обхода нужно в соответствующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые следует исключить, например когда IP-сеть уже указана в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — отдельные IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые необходимо исключить
  - Файлы **`*-user.txt`** автоматически появляются при первом запуске `zapret` или `service.bat`
