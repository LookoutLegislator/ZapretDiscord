> ### АНТИВИРУСЫ
> Антивирус может отреагировать на WinDivert.  
> WinDivert перехватывает и фильтрует трафик — без него zapret не сможет работать.
> Этот инструмент могут использовать как легитимные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы относят файлы WinDivert к потенциально опасным или хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите проверку PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить папку в список разрешённых; если нет — рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый способ
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Скачайте zip- или rar-архив со [страницы последнего релиза](https://github.com/LookoutLegislator/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Найти работающую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Включить запуск вместе с системой: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Ручной режим удобен для проверки разных стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — переключить режим обработки сервисов из `ipset-all.txt`.  
  Это может помочь при проверке ресурса, который без zapret работает, а с ним — нет  
  В скобках выводится текущий режим:
    - `none` — ни один IP не проверяется
    - `loaded` — проверяются IP, входящие в список
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить выбранный фейк на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В финале можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного сбоя
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должно появиться приложение winws.exe, отвечающее за обход, — его видно на панели задач.  
Если окна или процесса нет, обратитесь к [#522](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открывшегося блокнота
  - Через текстовый редактор с правами администратора откройте файл `hosts` в созданной папке
  - Вставьте скопированное содержимое в конец `hosts` (либо замените уже добавленные ранее аналогичные строки)
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа не гарантирована. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/LookoutLegislator/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Сначала выбранный вариант может справляться с задачей, но позже перестать работать после его обнаружения.
> В репозитории есть много стратегий обхода. Если ни одна не подходит, создайте собственную на основе одной из имеющихся и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок

- Проверьте, присутствует ли адрес ресурса в списках доменов или IP-адресов

- Попробуйте другие варианты (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие нужные данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y
- Удалите каталог zapret
- Возьмите свежую версию на [странице релизов](https://github.com/LookoutLegislator/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву, откройте свойства и, если внизу справа есть пункт разблокировки, выберите его, затем нажмите применить и ОК
- Распакуйте архив в новый каталог в корне диска, исключив пробелы, спецсимволы и кириллицу
- Запускайте разные скрипты `general` и проверяйте ресурсы. Если сайты не открываются, завершайте программу через значок замка на панели задач и пробуйте другую стратегию
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service` -> выберите нужную стратегию

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе обход может повлиять на неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Выключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- Также смотрите [#251](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён и настроен
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить именно её.
- В `service.bat` перейдите в `Run Diagnostics` и выполните очистку кэша Discord.
- Снова проверьте приложение Discord. Изменилось ли что-нибудь после очистки кэша?
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, временно пользуйтесь ей.
- Если Discord не открывается и в браузере, повторно протестируйте все стратегии. YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения есть в [#252](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/LookoutLegislator/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр существует много, поэтому проверить и исправить каждую отдельно невозможно.

Самый универсальный порядок действий:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не сработает, дополнительно попробуйте режим `ipset any`

Учитывайте, что `ipset any` может нарушить открытие большого числа сайтов. Не оставляйте этот режим включённым постоянно: выясните IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если результат отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/LookoutLegislator/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть находится в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — отдельные IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
